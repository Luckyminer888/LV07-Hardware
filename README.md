# Lucky miner - LV07 Hardware

Official hardware manufacturing files for the Lucky miner LV07.

This repository contains the manufacturing files for the Lucky miner LV07, including schematics, Gerber files, BOM, Pick & Place files, and 3D models.

## Repository Structure

```text
.
├── Schematic/        # Schematic PDFs
├── Manufacturing/    # Gerber, Drill, BOM, Pick & Place
├── 3D/               # STEP models
├── Images/           # Photos and renders
└── README.md
```

## Contents

* Schematic PDF
* Gerber files for PCB fabrication
* NC Drill files
* Bill of Materials (BOM)
* Pick & Place (Centroid) files
* STEP 3D model

## Manufacturing

The files required for PCB fabrication and assembly are located in the `Manufacturing/` directory.
